How CrewFocus Works

Practical rules from the current CrewFocus code. Choose a topic, then open only the question you need. Experimental behaviour and planned features are identified.

Getting around CrewFocus 4 topics
Focus and Dashboard

Focus shows the currently selected preparation stage, a current duty when applicable, and the next duty. Dashboard contains the working tools and planned modules. The main Focus/Dashboard tabs remain available at the top.

Automatic Focus timings

Dashboard → Settings → Focus settings lets you enable stages and set each stage’s lead time before sign-on. The stages include Trip Preparation, Flight Planning, Hotel & Transport, Commuter, and Departure Planning. As sign-on approaches, the enabled stage with the shortest reached lead time is selected. Days Off is the fallback. Selecting a manual Focus overrides automatic selection until automatic mode is restored.

Some stages are placeholders; selecting them does not make their planned features operational.

Returning to where you were

General Settings contains the page-resume duration, initially five minutes. If you leave Safari or reload within that period, CrewFocus attempts to restore the last page and scroll position. It does not automatically reopen modal dialogs. Flight Planning also rebuilds the saved NAIPS weather/NOTAM list without another Import tap. A full-screen iPad CBR preview is restored within the configured interval when possible. An alarm Shortcut return has its own departure-times restoration rule.

LIVE and TEST

The switch in the header changes the CBR testing context. In TEST, the displayed schedule can be treated as today where the date override is enabled. A test schedule is not an amended operational roster. Check that LIVE is selected for an actual duty.

Roster and duty 4 topics
Importing and reviewing the roster

Import a roster file or paste roster text. The parser creates dated duties and preserves the original sector text. Review and accept a duty before using its times for departure planning. Manually confirm every date, port, sector and local time; imported or scanned text may be misread.

Current duty, next duty and completed sectors

Focus chooses current/upcoming duties from the saved roster. Original roster sector lines remain in their existing format. A sector is struck through once its calculated arrival instant has passed, using the relevant airport time zones. Long turnarounds are highlighted only at the arrival airport on the preceding flight line; the departure airport on the following flight remains unhighlighted.

Standby and call-outs

Standby displays its start and finish without automatically creating alarms. Recognised call-out flying is separated from standby where possible so the original standby record can be retained for duty calculations. The user must confirm any roster interpretation.

Duty, maximum FDP and rest tiles

The Focus summary shows scheduled duty duration, a preliminary maximum FDP, calculated interval to the following sign-on, and preliminary minimum rest. The duty figure is amber at 60 minutes or less below the estimated FDP limit and red at 15 minutes or less (including exceedance). The rest figure is amber within 60 minutes above minimum and red within 15 minutes (including shortfall).

The maximum FDP is currently a Table A reference and cannot account for every acclimatisation, standby, early-start, disruption or special-duty rule. Do not use a green or neutral figure as an operational clearance.

Departure planning, alarms and Calendar 3 topics
Home and hotel departure times

Departure Planning works back from sign-on using travel/transport time, security or checkout allowance, and your adjustable earlier-time labels. Home travel can use configured routing, with manual override; hotel transport times can be stored and overridden. Check the actual transport arrangements and journey time.

Creating and changing alarms

The Set Alarm controls call an Apple Shortcut. CrewFocus cannot silently create, inspect, delete or amend Clock alarms. Creating a replacement alarm does not remove an old one, so review Clock for duplicates and repeating settings. The Shortcut return should restore Departure Times. Use Alarms & Shortcuts at the top of this Help page for the step-by-step setup guide.

Calendar export and changes

Calendar export is a manual copy of selected roster duties, not a live roster subscription. The app can use the configured iPhone Shortcut or offer an .ics file. Check previously imported events if the roster changes; duplicate-prevention tracking cannot guarantee a partly completed Shortcut added no events.

Crew Briefing Report (CBR) 4 topics
Selecting and confirming a CBR

Flight Planning → Duty → Update CBR lets you inspect the selected screenshot/PDF before using it. Text is extracted locally by the importer, then the date, sign-on and flight sectors must be reviewed and confirmed. If the image or parser is unclear, keep the existing confirmed CBR rather than accepting an unverified schedule.

A new duty versus an update to the same duty

When the confirmed duty date changes, CrewFocus starts a new briefing by clearing the previous weather archive, selected NOTAMs and alternate display. A same-day update retains briefing content. You can also request Start Fresh explicitly when selecting the file, or use Clear Previous Briefing to remove weather and selections without erasing your roster or CBR schedule.

Crew details and employee numbers

CBR crew extraction is reviewed separately. The generated sector columns order crew by role, with Captain first, then FO, cabin management, cabin crew and positioning crew as applicable. The importer attempts to distinguish current from previous employment numbers and may leave ambiguous fields blank for review. ORIG is the shortened crew-table header.

Operational notes and output

Operational notes are entered by sector and displayed in black under OPERATIONAL. The iPad CBR uses a fixed landscape PNG canvas (2360 × 2240 pixels) with a clock-safe area; it can be shared/opened as an image. The original CBR and a generated briefing are separate. A generated PNG is a planning aid, not an authoritative company briefing.

Weather: source and updates 4 topics
Where weather comes from

Weather is imported from a NAIPS location briefing pasted into Flight Planning. Automatic NAIPS fetching is not connected. All TAF, METAR/SPECI and ATIS information depends on what the imported source contains. A missing or invalid TAF is flagged for verification rather than treated as good weather.

Updating one airport without erasing other sectors

CrewFocus stores weather by airport. A new briefing for BNE can add newer BNE products while the previously imported MEL/ROK products remain available to their sectors. It keeps a limited archive of original weather reports per airport and chooses products applicable at each visit time. Do not mistake a retained historical TAF for a current operational forecast.

Previous sector weather after a new TAF

After the airport arrival instant has passed, the sector is struck through on Focus. Updating later weather does not automatically delete an earlier report that was used for an already completed sector. At a turnaround, the compact CBR shows arrival and departure weather separately, and screens temporary changes against each configured event window. Historic weather remains available to reconstruct earlier sectors where relevant.

Current TAF, SPECI and changes

TAF validity is checked against the airport event, in UTC. FM/BECMG and temporary/probability groups are interpreted in their specified periods; an INTER/TEMPO group that only intersects a broader screening window is not automatically considered active at the exact flight event. SPECI is an observation, not a replacement TAF. Changed forecast groups can receive a black revision bar; significant groups use distinct colour highlighting.

Weather screening and alternates 4 topics
Duty screening window

For imported CBR weather, the overall window starts a configurable number of hours before sign-on (default 1 hour) and ends after sign-off (default 4 hours). Each airport has independently adjustable before/after arrival and before/after departure windows. Those event windows determine screening; the broad duty window alone does not prove applicability at an airport. Times from different ports are converted to UTC for comparison.

How alternate airports are chosen

ALTERNATES uses airports in the most recently accepted NAIPS briefing that are not already CBR duty-visit airports. It does not pull old alternate airports back out of the archived sector-weather cache. A new duty confirmation clears the earlier alternate selection.

Which alternate TAF groups appear

The alternates column screens each TAF against the complete confirmed CBR duty window (there is no scheduled alternate arrival/departure time) and selects the latest issue for each covered portion. It displays the applicable prevailing and overlapping FM/BECMG/INTER/TEMPO/PROB groups, without the raw TAF issue header, temperature, QNH or out-of-window change groups. Black change bars and weather colours are retained. Buffer-only temporary changes are amber; overlapping core-duty significant changes are red.

Why an alternate may be absent or flagged

An alternate does not appear if it is not present as a TAF airport in the last briefing, or if it is already one of the duty airports. A forecast that does not cover the screened period is flagged for verification. CrewFocus does not invent a replacement forecast or assume an airport has acceptable alternate weather.

NOTAM screening and selection 6 topics
Imported NOTAMs and age categories

NOTAMs come from the imported NAIPS briefing. The advisory shortlist evaluates recognised validity dates and UTC operating periods against the saved duty. Clearly applicable items remain prominent; excluded or expired items are moved lower (red), and uncertain timing/overlap is retained for manual review (amber). Low-priority notices may be grouped separately. The original text remains accessible for verification.

Which operating schedules can be assessed

The parser recognises some explicit start/end UTC dates, plain DAILY time ranges (including overnight), and selected HJ/HN daylight-only periods where airport coordinates are supported. Combined, weekday-specific or unrecognised schedules require manual review; a questionable time rule must not silently exclude an item.

NOTAM settings and sector windows

Flight Planning Settings has four independent airport screening windows: arrival before/after and departure before/after (default 1 h / 2 h and 1 h / 1 h). Airport events are compared in UTC; a long turnaround does not create an uninterrupted screening period. The separate duty-wide window remains reference context for alternates.

Selecting a NOTAM for a specific sector

Shortlisting does not automatically add a NOTAM to the iPad CBR. The pilot selects relevant items. Assignment checks the matching airport and its independently configured arrival/departure screening windows, including recognised daily activation periods. Unknown times require review; an item outside both windows is not assigned simply because the airport matches.

Aircraft-specific exclusions

The aircraft selector currently includes B737-800, MAX 8 and MAX 10. Conservative screening can exclude clearly A380-only, higher-code-only or certain above-wingspan restrictions. A maximum-permitted Code E notice still includes Code C and should not be screened out on that basis. This is a limited filter, not a comprehensive aircraft-performance or regulatory assessment.

NOTAM learning: what works now

When manually adding a NOTAM, CrewFocus can record why it mattered (runway, approach, performance, operational or other), the original text and airport visits. These decisions can be backed up and restored. Automatic learning-based selection is planned, not active; saved decisions do not currently train a live model that can authorise future selections.

Duty and rest calculators 3 topics
Maximum FDP calculator

Dashboard → Calculators → Maximum FDP uses sign-on date/time and zone, duty type, sector count and acclimatisation inputs to display a reference result. Standby and special circumstances require additional conditions. Table A assumptions are not a substitute for approved operational documents or fatigue assessments.

Required Rest calculator

The Required Rest calculator can load a rostered duty or accept manual times. Sign-off is estimated as final landing plus 30 minutes for domestic or international flying duty; the code adds 30 minutes to minimum rest after an international final sector. Other conditions (including actual delays, local nights, standby and special duty) still require checking.

How Focus obtains its rest figures

Focus estimates duty from rostered sign-on to sign-off and rest from that sign-off to the next rostered sign-on. Where required duty data, sector classification or next sign-on is absent, it shows a dash rather than creating a number. The provisional minimum uses the greater of 12 hours or preceding duty duration, plus the applicable international final-sector increment; not every required rest rule is modelled.

Checklist, tiles, ideas and documents 4 topics
Trip Checklist

The packing checklist supports packed, not-coming and undecided states, custom rows and reorder controls. Choices are saved in this browser. Clearing ticks does not delete the checklist itself.

Rearranging Dashboard tiles

Hold a Dashboard tile to enter the wobbling edit mode. Hold again to lift and move it; normal swipes should scroll the page without moving tiles. A persistent Done button exits edit mode. Your custom ordering is stored locally and can be reset.

Editable Things to Come

Every Dashboard tile has its own collapsed, editable Things to Come list. Expand to read bullet points, choose Edit, then Save & collapse. These are project notes only and do not activate new functionality. Export an ideas backup to preserve or transfer them.

Document Library

The library stores selected aviation documents locally in the browser. Uploaded documents are not automatically interpreted or applied to CBR weather, NOTAM decisions or the FDP calculator. Confirm you are using current approved references independently.

Data, limitations and troubleshooting 4 topics
What is stored on the device?

Most preferences, roster state, imported briefing text, weather archive, CBR selections, tile order and ideas use browser storage; some library documents use local IndexedDB. It is not a multi-device synchronisation service. Removing Safari website data can remove the saved information. Back up important ideas and learning records separately.

Missing weather or briefing changes

First check the confirmed duty date and its time zones, then verify the source NAIPS briefing contains the required airport and a TAF valid at its visit time. The latest NAIPS import controls alternates; the archive is retained only for sector weather history. A new-day CBR confirmation or explicit Clear Previous Briefing resets those products and selections.

Planned versus available tools

Commuter flight search, hotel/CATS automation, Pay Calculator, Aircraft Tracking and Logbook automation are development ideas or placeholders. The Logbook stores ideas only. Automatic NAIPS retrieval and self-learning NOTAM selection are not connected. Working modules should not be described as complete until independently validated.

Safety, source of truth and feedback

CrewFocus is a personal planning assistant and some calculations and weather/NOTAM interpretations are experimental. Use the current official operational documents, NAIPS briefing, company procedures and human cross-checks as the source of truth. For a suspected problem, retain the original source, report the affected airport/sector, and note the CrewFocus version.

Reference: CrewFocus v252 implementation. Guidance is descriptive, not operational approval. Use current authorised aviation material for decisions.

Standby types

Standby A: A timed standby duty at home base (maximum 12 hours). If called out, total duty starts when standby begins. Standby already served counts towards the combined duty limit. The available flying FDP depends on both the standby-start and flight sign-on time bands.

Standby 18: An opted-in calendar-day availability arrangement. The assigned duty normally requires at least 18 hours’ notice, issued by 1800 the previous day. It is not the same timed Standby A call-out calculation.
