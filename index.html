CrewFocus wallpaper calibration

Dedicated calibration file to measure how the exported PNG is scaled and cropped by iPad wallpaper. This is a measurement step, not a band-aid fix.

Version 175 Canvas 2732 × 2048 Landscape wallpaper test PNG export

What this file does

  1. Creates a calibration PNG with perimeter borders, nested safe rectangles, centre lines, left widget guide, and labelled grid markers.
  2. Lets you preview that same PNG on the iPhone before export.
  3. Exports / shares the calibration PNG so you can AirDrop it to the iPad and test it as wallpaper.
  4. Gives us measurable evidence of the real crop / scale so the next briefing renderer can be built properly.

Test steps

1. Open preview here on iPhone. 2. Share / AirDrop the PNG to iPad. 3. Save it to Photos and apply as wallpaper. 4. Send back screenshots of: • iPhone preview • transferred image • wallpaper default placement • wallpaper after any manual fit/zoom
What to look for: • which outer border is clipped • which safe rectangles stay visible • where the left widget box lands • how much of the blue banner survives • how much the image is enlarged on wallpaper
